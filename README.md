# Vietnam Culinary Adventure — Premium

A mobile-first culinary-tour landing page concept for Saigon, Da Nang and Hanoi.

## Preview locally
Open `index.html` in a browser. The page uses remote Unsplash images and Google Fonts.

## Included
- Responsive editorial-style homepage
- Destination storytelling for Saigon, Da Nang and Hanoi
- Tour cards and city filters
- Tour detail modal and demo enquiry form

## Important
This is a frontend prototype. Enquiries are stored in the visitor's browser localStorage only. No live booking backend, email delivery, payment, authentication, or production admin is connected. Replace sample reviews and verify all prices, tour details, image rights and business claims before launch.
